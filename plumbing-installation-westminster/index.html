What should I tell a plumber before a plumbing installation?

Describe what you want installed, where it will go, and what is currently there if you know. Mention any timing needs and ask what details the plumber needs before discussing the work.

Should I try to remove an existing fixture before calling?

Not if you are unsure how it is connected or how to shut off the water. Explain the situation and ask the plumber what, if anything, you should prepare.

When should I call a plumber about an installation?

Call when you are planning work that involves plumbing connections or when you are not sure what the installation requires. A plumber can discuss the requested scope and what information is needed next.
